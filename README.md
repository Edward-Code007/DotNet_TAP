# DotNet_TAP
Este proyecto tiene como objetivo recopilar y demostrar diversos patrones y casos de uso del modelo Task-based Asynchronous Programming (TAP) en .NET. Incluirá ejemplos prácticos que abarcan desde operaciones básicas con Task y async/await, hasta escenarios más avanzados como manejo de cancelaciones, composición de tareas, paralelismo controlado .
